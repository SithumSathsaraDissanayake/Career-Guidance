## 📖 About the Project

The **Career Guidance & Skill Development Web System** is designed to guide students in choosing the right career path by analyzing their skills, interests, and educational background. The system provides personalized career recommendations, skill development resources, and progress tracking.

This project is being developed as part of the **HNDIT academic program** at SLIATE.

---

## ✨ Key Features

- 🎯 Skill assessment quiz to identify student strengths and interests
- 📊 Personalized career path recommendations
- 📚 Course and resource suggestions for skill improvement
- 👤 Multi-role system (Student, Admin, Counselor)
- 📈 Progress tracking dashboard
- 🛠️ Admin panel to manage careers, skills, and users
- 🔐 Secure login and authentication system
